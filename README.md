# Yaser Mansouri — Personal Website

Personal academic and professional portfolio website for **Yaser Mansouri, PhD**.

## Local preview

From the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

For the user site `yasermansouri.github.io`, keep `index.html` at the repository root and publish the `main` branch from `/ (root)`.

## Structure

- `index.html` — page structure and content
- `style.css` — presentation and responsive styling
- `script.js` — navigation and JSON-driven sections
- `data/` — certifications, career, projects, publications
- `image/` — profile image
- `cv/` — downloadable CV files
